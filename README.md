# Pocket Life

A "life in your pocket" mobile game. Make your own person, then live a real-time life in a soft low-poly world that starts from nothing. Early prototype, v0.0.4.

**Play the test build:** https://lukeogston97-hash.github.io/pocket-life/

## What's here
- `index.html`: the whole game (three.js, no build step)
- `game-data.json`: all the content (items, recipes, needs, looks, settings), with a help section inside the file
- `CLAUDE.md`: the design decisions and rules Claude Code follows when building it

## Updating the game
Open this repo in Claude Code (web, phone or computer) and ask for a change. Every push to `main` updates the test link.
