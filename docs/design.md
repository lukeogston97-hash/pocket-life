# Pocket Life: design notes

Luke's mobile "life in your pocket" game: SEED meets One Hour One Life. Built step by step with Claude.

Every decision so far, split by area so an update only reads the file it needs. When something is decided, add it to the file for its area (or a new file, listed here).

- docs/adding.md: how to add items, recipes, placeables, live settings, actions and admin tools (start here)
- docs/design/basics.md: look, clock, age, needs, walking, controls
- docs/design/online.md: one shared world, chat, safety, the first admin tools
- docs/design/away.md: what your person does while you're away; timing, sleep and death
- docs/design/needs-and-crafting.md: crafting, chopping, rest, stamina, tall grass, held tools
- docs/design/placeables.md: campfires, fuel, sitting
- docs/design/claims.md: campfire claims (who can do what where, fuel, away people)
- docs/design/societies.md: societies (player groups sharing one claim: invites, leader, leaving, the admin's list)
- docs/design/inventory-and-menus.md: inventory grid, Craft, recipe discovery, tap menus, stations, pack up
- docs/design/admin.md: admin mode (the way in, the dashboard, tapping things), live settings and item numbers, people, fires and claims, the Log, Restore
- docs/design/later.md: sign-in, buildings, later ideas
- docs/design/code.md: how the code is laid out, the server, Cloudflare's free plan
- docs/design/working.md: versions, test then release, checks
